# 首页与扩展组件

LifeOS 首页首先服务固定工作流，扩展组件只是可选的补充视图。

## 固定首屏

首页核心结构围绕：

1. 今日重点；
2. 快速收集；
3. 收集 → 安排 → 专注 → 沉淀 → 回顾；
4. 今天的节奏；
5. 正在推进的项目；
6. 最近笔记。

首页不是“万能小组件墙”，核心工作流不依赖任何扩展组件。

## 内建扩展组件

LifeOS 只维护直接使用本地工作区数据或本地生产力状态的内建组件：

- 任务概览；
- 即将到来的日程；
- 最近笔记；
- 习惯概览；
- 番茄钟；
- 收藏；
- 活动记录；
- 精力追踪；
- 项目组合；
- 每周洞察；
- 快速添加；
- 快捷键。

新闻、行情、社交媒体、天气、娱乐、随机内容和开发者门户类组件不再作为 LifeOS 核心能力维护。

## 自定义组件

如果你需要 RSS、JSON API、Markdown 或 LifeOS Store Query，可以使用自定义组件显式配置数据源。使用远程数据源时，请自行确认请求目标和隐私影响。

## 原则

- 扩展组件不抢首页固定工作流的视觉优先级；
- 同一领域复用现有 Store，不在 Widget 内重新实现业务状态；
- 默认安装不启用扩展组件；
- AI 使用独立入口，不作为第二套首页 AI Widget 出现。
