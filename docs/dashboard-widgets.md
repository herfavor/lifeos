# 首页与扩展组件

LifeOS 首页先服务固定工作流，再提供可选扩展组件。

## 固定首屏

当前首页核心结构是：

1. 今日工作台 / 最重要下一步
2. 快速收集
3. 收集 → 安排 → 专注 → 沉淀 → 回顾
4. 今天的节奏
5. 正在推进的项目
6. 最近笔记
7. 折叠的扩展组件区域

这部分不是可随意替换的“小组件墙”，而是产品主流程。

## 扩展组件

页面底部“我的扩展组件”用于按需加入天气、工具、信息源等附加内容。

扩展组件应满足两个原则：

- 不抢首页固定工作流的视觉优先级；
- 只添加你会持续查看的内容。

AI 不是首页组件。AI 有独立一级入口 `/ai`。

## 隐藏能力

扩展组件可见性同样受 `src/config/features.ts` 约束。表单、闪卡、Quest / XP、生产力评分等隐藏能力不会通过组件管理器重新回流。

## 性能建议

- 少量、常用即可；
- 网络型组件会产生第三方请求；
- 不需要时关闭自动刷新；
- 页面和组件使用按需加载，仍应避免堆积大量实时组件。
