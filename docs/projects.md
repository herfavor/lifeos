# 项目

项目页用于围绕**结果、下一步和里程碑**推进工作，而不是把所有分析图表都堆在首屏。

## 核心用途

- 创建和查看项目
- 关联任务
- 追踪项目进度
- 看清当前下一步
- 管理里程碑和截止信息

全局页头的项目上下文可以帮助任务、日程、笔记等页面聚焦当前项目。

## 高级分析

跨项目统计放在 **更多功能 → 项目组合**（`/portfolio`）。

项目分析只在有足够数据时才有意义；没有资源、基线或样本时，界面应显示“数据不足”而不是伪造健康度结论。
