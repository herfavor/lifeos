# 任务与看板

任务页管理的是**已经明确、可执行的工作**。

收件箱 backlog 已与任务页拆开，因此默认任务看板不会再出现“收件箱”列。

## 默认任务页

`/tasks` 重点保留：

- 看板
- 列表
- 搜索 / 筛选
- 新建与编辑任务
- 任务详情、子任务、清单、评论等

看板卡片和列使用更轻的边框与更少阴影，优先保证扫描速度。

## 高级视图

为了避免任务页变成所有工作工具的总入口，高级视图从主表面降级：

- 甘特图：`/tasks?tab=timeline`
- 习惯：`/tasks?tab=habits`
- 资源：兼容深链保留

日历属于日程页，不再作为任务看板的同级视图。

## 状态与收件箱

`backlog` 用于收件箱。正式工作流使用待办、进行中、复核、完成等状态。

将收件箱卡片点击“安排”后，会移动到正式待办。

## 快捷键

看板获得焦点且不在输入框中时：

- `J / K`：上下任务
- `H / L`：左右列
- `N`：当前列新建任务
- `E`：编辑
- `D`：删除 / 归档动作（以当前 UI 为准）
