# 时间统计

时间统计是日程体系的辅助工具，用来记录“实际花了多少时间”，而不是替代日历。

## 入口

- 侧栏 **更多功能 → 时间统计**
- 路由：`/time`
- 兼容目标：`/schedule?tab=timer&section=timer`

## 当前能力

计时区域仍保留：

- 计时器
- 时间记录
- 工时表
- 汇总
- 时间线

代码中还保留更完整的项目、发票、报表和设置能力，其中自由职业 / 计费相关入口默认隐藏。

## 与专注的关系

- **任务**：我准备做什么
- **专注模式**：我现在只做什么
- **番茄钟**：我采用什么节奏
- **时间统计**：我实际花了多久

AI 也可以启动 / 停止计时和补录时间记录。
