# 核心工作流

LifeOS 的主线是：**收集 → 安排 → 专注 → 沉淀 → 回顾**。这篇指南把今天、收件箱、项目、任务和回顾放在同一个流程里说明。

## 收集：未决定的内容进入收件箱

收件箱（`/inbox`）保存 `backlog` 状态，也就是还没有完成安排决定的输入。

```text
收件箱（未决定） → 选择项目 / 日期 → 安排 → 正式任务
```

默认同时展示多个待处理项：

- **需要安排**：项目或日期仍缺失；
- **可以直接进入待办**：信息已经明确，只需确认进入正式任务流。

如果你想一次只处理一项，可以使用“专注分拣”。旧地址 `/tasks?tab=inbox` 会兼容跳转到 `/inbox`。

## 安排：今天、项目和任务各有边界

### 今天

“今天”（`/today`）只回答：**今天真正要完成什么？**

适合放入今日视图的内容包括今日到期任务、正在进行中的工作、今天的日程，以及从收件箱明确安排到今天的事项。还没决定的内容继续留在收件箱。

### 项目

项目页围绕结果、下一步和里程碑推进工作，适合：

- 创建和查看项目；
- 关联任务；
- 追踪进度；
- 管理里程碑和截止信息；
- 通过项目上下文聚焦任务、日程和笔记。

跨项目分析属于高级能力，可从“更多功能 → 项目组合”进入。

### 任务

任务页（`/tasks`）管理已经明确、可执行的工作。默认保留看板、列表、搜索/筛选、新建/编辑以及任务详情、子任务、清单和评论等能力。

`backlog` 不会重复出现在正式任务看板。高级视图按需进入：

- 甘特图：`/tasks?tab=timeline`
- 习惯：`/tasks?tab=habits`

## 执行：把任务和时间结合起来

“任务”描述要做什么；具体时间承诺交给日程；专注模式、番茄钟和时间统计负责执行节奏。详见 [日程、专注与时间](./schedule-and-focus.md)。

## 沉淀：结果进入笔记和收藏

完成任务后的记录、经验和外部资料应进入笔记与收藏，而不是继续堆在任务描述里。详见 [笔记与收藏](./knowledge.md)。

## 回顾：关闭开放循环

回顾页（`/activity`）用于查看最近活动、已完成工作和仍未结束的开放循环，并跳回任务、笔记或项目继续处理。

更完整的周复盘位于“更多功能 → 每周回顾”（`/retrospective`）。数据不足时应明确显示数据不足，而不是生成虚假的健康度结论。

## 推荐习惯

1. 输入时先收集，不急着填满所有字段；
2. 每天固定处理收件箱；
3. 只有决定要做的事项才进入任务；
4. 有明确时间承诺的内容安排进日程；
5. 完成后把可复用信息沉淀到笔记；
6. 通过日常/每周回顾关闭开放循环。
