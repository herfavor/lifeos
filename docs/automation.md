# 自动化快速上手

LifeOS 的自动化用于处理反复出现的任务流程。规则、执行和历史记录都在你的设备上运行，不经过 LifeOS 服务器。

> 本页只描述当前界面中已接通的能力。类型定义中保留的定时、逾期等未接入触发器不会出现在新建规则界面。

## 创建规则

1. 在侧边栏的「更多功能」中打开 **自动化**。
2. 点击 **新建规则**。
3. 输入一个能说明用途的名称，并选择触发器。
4. 需要时开启「仅当」，配置一个条件。
5. 选择操作并填写必需配置。
6. 点击 **创建规则**。新规则默认启用，可随时停用。

当前创建器为每条规则配置一个触发器、最多一个条件和一个操作。存储层依然兼容历史上的多条件/多操作规则。

也可以从页面上的安全模板开始。保存前可编辑模板；已有规则支持编辑、复制和「试运行」。试运行只检查所选任务是否满足条件并展示计划操作，不写入任何数据。

## 已接通的触发器

| 触发器 | 何时运行 |
| --- | --- |
| `task.created` | 新任务写入看板后 |
| `task.moved` | 任务移动到另一状态后 |
| `task.completed` | 任务移动到完成状态后 |

## 可选条件

条件不匹配时，规则会安全跳过，不记为执行错误。

- 字段：状态、优先级、标签、标题、描述、截止日期、预估工时、进度。
- 运算：等于、不等于、包含、不包含、大于、小于、已设置、未设置。

例如：「任务已创建」+「优先级等于 high」+「添加 urgent 标签」。

## 已支持的操作

- 移动任务/设置状态
- 设置优先级
- 添加或移除标签
- 添加评论
- 设置截止日期
- 设置预估工时
- 复制任务
- 显示本地通知
- 归档任务

操作参数会在创建时校验。例如「设置优先级」必须选中低/中/高其中一项，防止保存一条看似正常但不会生效的规则。

## 管理与执行历史

- 顶部总览显示活跃规则、正在运行的规则和执行记录数量。
- **停用/启用** 只改变规则状态，不删除配置。
- **归档**会停用规则并让它退出活跃列表，可从「已归档」恢复。
- **删除**先进入回收站；可恢复，只有回收站中的「永久删除」不可撤销。
- **执行历史**显示规则、目标任务、执行时间、操作数量和错误，可精确打开目标任务；失败项可在规则和任务仍存在时重试。历史是当前运行期记录，不随规则一起持久化。

引擎带有 10 层递归保护，避免多条规则互相触发时无限循环。

## 旧备份恢复

当前版本会在加载时逐条修复旧自动化数据：

- 旧的 `trigger.event` 会迁移到 `trigger.type`。
- 单个 `action` 会迁移为 `actions[]`。
- `action.params` 会迁移为 `action.config`。
- 某条无法识别的记录会被跳过，不会连带其他有效规则一起清空。

如果页面仍异常，请先刷新，然后在 **设置 → 备份** 导出当前数据。错误恢复页不会自动删除你的数据。

## 与 AI 指挥中心配合

在 AI 的 **工具模式** 中，可以查询、创建、启停和删除自动化规则。新用户默认使用“自动执行”：可撤销写操作会直接执行并进入操作记录；高风险删除仍按 runtime 安全策略要求确认。
