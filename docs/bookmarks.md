# 收藏

收藏页（`/links`）用于保存以后还想看的外部资料，并把它们继续变成行动或知识。

## 常用能力

- 添加链接
- 搜索
- 文件夹 / 集合整理
- 收藏标记
- 归档
- 回收站
- 标签与分类
- 网格 / 列表视图

每条链接的更多菜单还可以创建任务、保存为笔记、编辑、收藏 / 取消收藏、归档和删除。

## 整理工具

导入 / 导出、AI 分类、重复链接检测等属于管理型能力，不应比“保存和找到链接”更抢眼。

## 生命周期

删除先进入回收站；回收站中再执行永久删除。
