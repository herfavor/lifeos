# 快速入门

LifeOS 的主线只有五步：**收集 → 安排 → 专注 → 沉淀 → 回顾**。第一次使用时，不需要先配置所有高级模块。

## 1. 先认识本地数据

LifeOS 是 local-first 应用。主要数据保存在当前浏览器 / PWA 的 IndexedDB 中。

建议第一天就进入 **设置 → 备份**，确认你知道如何导出 `.brain` 文件。

> `http://localhost:5173`、`http://localhost:4173` 和正式 HTTPS 域名是不同 origin，数据不会自动互通。

## 2. 从首页开始

首页不是“所有功能入口”的集合，而是当前行动驾驶舱：

- 顶部帮助你决定今天最重要的下一步；
- 快速收集支持任务 / 笔记；
- 工作循环固定为收集、安排、专注、沉淀、回顾；
- 今日区提醒你安排少量真正重要的事项；
- 项目和最近笔记只提供必要上下文；
- 扩展组件放在首屏之后。

## 3. 未决定的输入进收件箱

收件箱保存 `backlog` 状态。

默认会同时展示多个待处理项，并分为：

- **需要安排**：还缺项目或日期；
- **可以直接进入待办**：项目和日期已经明确。

选择项目、日期后点击 **安排**，任务会离开收件箱进入正式任务流。

如果你只想一次处理一项，可以切换到 **专注分拣**。

## 4. 任务只放“已经决定要做”的事

任务页默认只强调正式工作，收件箱 backlog 不再重复显示在任务看板。

高级任务视图仍可通过“更多功能”进入：

- 甘特图：`/tasks?tab=timeline`
- 习惯：`/tasks?tab=habits`

## 5. 有明确时间承诺的内容放进日程

- 日程：`/schedule`
- 时间统计：`/time`
- 番茄钟：`/schedule?tab=pomodoro`
- 专注模式：`/focus`

时间统计和番茄钟是辅助工具，不和日历争夺一级导航。

## 6. 结果沉淀到笔记和收藏

笔记默认突出普通笔记与每日笔记。知识图谱是高级能力，按需进入。

收藏用于保存外部资料；每条链接可以继续转成任务或笔记。

## 7. 最后配置 AI

打开侧栏一级入口 **AI**，或按 `Ctrl/Cmd + Shift + A`。

在 **设置 → AI 提供商** 配置 API key 和模型。新用户默认是“自动执行”：可撤销的本地写操作直接完成；删除等高风险操作仍需确认。

不希望 AI 写数据时，可切换为“每次确认”或“只读”。

## 8. 想安装成独立窗口

```bash
npm run build
npm run preview
```

打开 `http://localhost:4173`，从 Chrome / Edge 安装 LifeOS PWA。

详见 [PWA 安装与本地使用](./install-pwa.md)。
