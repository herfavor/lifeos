# 日程与事件

日程页管理**有具体时间承诺**的事项。

`/schedule` 默认进入日历规划界面。时间统计和番茄钟仍存在，但被明确视为辅助工具。

## 日历

当前日程支持月 / 周 / 日 / 议程等视图，以及事件创建、编辑、筛选、导入导出等能力。

月视图采用更紧凑的日期网格，并给近期安排留出空间，避免日历本身占满整页。

## 时间统计与番茄钟

- 时间统计：`/time` → 兼容跳转到 `/schedule?tab=timer&section=timer`
- 番茄钟：`/schedule?tab=pomodoro`
- 专注模式：`/focus`

它们不是日程一级标签的主要心智。

## 什么时候用任务，什么时候用日程

- “这周要做完” → 任务
- “周三 15:00 开会” → 日程
- “今天找 90 分钟写方案” → 可把任务安排成日程时间块
- 还没决定 → 收件箱

## 导入 / 导出

日程支持 ICS 等标准格式。大规模导入前建议先导出全量备份。
