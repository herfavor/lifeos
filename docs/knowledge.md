# 笔记与收藏

LifeOS 的长期沉淀层由两部分组成：

- **笔记**：保存你自己的知识、过程与结果；
- **收藏**：保存外部资料，并决定是否进一步转成任务或笔记。

## 笔记

主要入口：`/notes`。

默认突出普通笔记和每日笔记；知识图谱属于高级能力，可通过 `/notes?tab=graph` 进入。

编辑器基于 Lexical，支持常见富文本、列表、代码、表格、链接、Wiki Link、标签、附件、目录和版本等能力。

关系能力包括：

- 反向链接；
- 未链接提及；
- 失效链接；
- 关联日程；
- 知识图谱。

这些关系信息按需展开，不应长期挤占正文。

### 删除与恢复

普通删除进入回收站；恢复和永久删除分开。永久删除不可撤销，执行前需要确认。

### 常用快捷键

- `Ctrl/Cmd + N`：新建笔记；
- `Ctrl/Cmd + D`：每日笔记；
- `Ctrl/Cmd + Shift + E`：导出；
- `Ctrl/Cmd + B / I / U`：常见格式；
- `/`：斜杠命令；
- `[[`：Wiki Link。

## 收藏

收藏页：`/links`。

常用能力包括添加链接、搜索、文件夹/集合、收藏标记、归档、回收站、标签与分类，以及网格/列表视图。

每条链接可以继续：

- 创建任务；
- 保存为笔记；
- 编辑元数据；
- 收藏/取消收藏；
- 归档；
- 删除。

导入/导出、AI 分类和重复链接检测属于管理能力，不应比“保存和找到链接”更抢眼。

## 建议工作方式

1. 外部资料先进入收藏；
2. 需要行动的内容转成任务；
3. 需要长期保留的理解和结论转成笔记；
4. 定期归档或删除不再有价值的资料。
