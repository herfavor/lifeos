# 今天

“今天”页只回答一个问题：**今天真正要完成什么？**

它不是完整任务库，也不是日历的复制品。

## 与首页的区别

- **首页**：全局驾驶舱，帮助你决定下一步。
- **今天**：聚焦当日承诺、时间和节奏。

适合进入今天的内容包括今日到期任务、正在进行中的工作、今天的日程，以及从收件箱安排到今天的事项。

还没决定的输入应先放收件箱。

## 相关入口

- 收件箱：`/inbox`
- 任务：`/tasks`
- 日程：`/schedule`
- 专注：`/focus`
