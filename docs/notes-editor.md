# 笔记

笔记是 LifeOS 的长期沉淀层。默认界面优先保证阅读与写作，知识图谱和回收站属于按需进入的次级能力。

## 主要入口

`/notes`

默认突出：

- 笔记
- 每日笔记

按需进入：

- 知识图谱：`/notes?tab=graph`
- 回收站：通过笔记页相关入口进入

## 编辑器

当前编辑器基于 Lexical，支持常见富文本、列表、代码、表格、链接、Wiki Link、标签、附件、目录、版本等能力。

正文使用更适合长期阅读的行高和宽度；工具条保留完整能力，但默认视觉层级更加克制。

## 关联与提及

反向链接、未链接提及、失效链接与关联日程默认折叠。关系信息存在，但不长期挤占正文。

## 知识图谱

知识图谱是高级能力。当前布局增加：

- 更大的节点 / 标签碰撞空间
- 更松的连接距离
- 自动 fit-to-view
- 更稳定的中心力与衰减
- 拖动后保留本次手动位置

## 删除与恢复

普通删除进入回收站；恢复和永久删除分开。永久删除不可撤销，执行前应确认。

## 快捷键

- `Ctrl/Cmd + N`：新建笔记
- `Ctrl/Cmd + D`：每日笔记
- `Ctrl/Cmd + Shift + E`：导出
- `Ctrl/Cmd + B / I / U`：常见格式
- `/`：斜杠命令
- `[[`：Wiki Link
