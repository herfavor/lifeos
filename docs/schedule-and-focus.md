# 日程、专注与时间

LifeOS 把“什么时候做”“现在怎么做”“实际花了多久”拆成不同能力，避免日历、番茄钟和时间记录混成一个概念。

## 日程：具体时间承诺

日程页（`/schedule`）管理有明确时间的事项，支持月 / 周 / 日 / 议程视图，以及事件创建、编辑、筛选和导入导出。

判断原则：

- “这周要做完” → 任务；
- “周三 15:00 开会” → 日程；
- “今天找 90 分钟写方案” → 把任务安排成时间块；
- 还没决定 → 收件箱。

日程支持 ICS 等标准格式。大规模导入前建议先导出全量备份。

## 专注：现在只做什么

专注模式入口：`/focus`。

它用于减少当前执行时的干扰，不替代任务管理，也不维护第二套任务数据。

## 番茄钟：执行节奏

番茄钟入口：`/schedule?tab=pomodoro`。

Dashboard 番茄钟与完整番茄钟共用同一个 `usePomodoroStore`，因此开始、暂停、继续和重置使用同一状态真源。

## 时间统计：实际花了多久

入口：

- 侧栏“更多功能 → 时间统计”；
- `/time`；
- 兼容目标：`/schedule?tab=timer&section=timer`。

当前能力包括计时器、时间记录、工时表、汇总和时间线。

概念边界：

- **任务**：我准备做什么；
- **专注模式**：我现在只做什么；
- **番茄钟**：我采用什么节奏；
- **时间统计**：我实际花了多久。

AI 也可以启动/停止计时和补录时间记录，但仍复用现有业务 Store。
