# 收件箱

收件箱保存的是**还没有完成安排决定**的输入。它和任务页是两个不同阶段。

```text
收件箱（未决定） → 选择项目 / 日期 → 安排 → 任务（已承诺）
```

## 默认视图

收件箱会同时展示所有当前可处理的 backlog 项，而不是一次只显示一张卡。

### 需要安排

项目或日期仍缺失。每张卡可以直接选择项目、设置日期、打开详情，或点击“安排”进入待办。

### 可以直接进入待办

项目和日期已经明确，只需要确认是否进入正式任务流。

## 专注分拣

如果你想一次只处理一项，点击 **专注分拣**。这是可选模式，不是默认入口。

## 与任务页的边界

- 收件箱数据状态：`backlog`
- 正式任务页不再重复展示 backlog 列
- 老地址 `/tasks?tab=inbox` 会兼容跳转到 `/inbox`

## 推荐习惯

1. 想法先收集，不要在输入时就填满所有字段；
2. 每天固定一两次处理收件箱；
3. 能删除或归档的不要强行变成任务；
4. 真正决定要做时，再进入正式任务。
